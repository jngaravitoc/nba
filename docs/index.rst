.. module:: nba

***
nba
***

N-body Analysis (``nba``) is a Python package to analyze N-body simulations of
galaxies: reading snapshots, finding the centers of halos, density and
kinematic profiles, orbits, and sky maps. It was written for the MW-LMC
simulations of Garavito-Camargo et al. (2021, GC21) and works with any
Gadget-4 HDF5 snapshot.

``nba`` is developed in a `public repository on GitHub
<https://github.com/jngaravitoc/nba>`_. Bug reports and feature requests are
welcome as `GitHub issues <https://github.com/jngaravitoc/nba/issues>`_.
