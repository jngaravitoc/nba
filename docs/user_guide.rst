**********
User guide
**********

The user guide describes the modules of ``nba``, with examples, and links to
the API reference of each one. The :doc:`tutorials` show how they work
together on real simulations.

.. toctree::
   :maxdepth: 1

   ios/index
   com/index

More modules (``nba.orbits``, ``nba.structure``, ``nba.kinematics``,
``nba.cosmology``, ``nba.visuals``, ``nba.utils``) will be documented here; in
the meantime see their docstrings and the `README
<https://github.com/jngaravitoc/nba#readme>`_.
